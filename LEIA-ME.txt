92 horas / 31 encontros. Aulas disponíveis neste pacote: A01, A02, A03, A04.
Extraia o ZIP inteiro. Execute npm start nesta pasta ou abra index.html diretamente.
Node.js 18+; servidor sem dependências, sem npm install. Ctrl+C encerra o servidor.
P alterna a grade; o botão de apresentação amplia a leitura.
Página e arquivos locais offline; instalações e fontes externas podem precisar de internet.
Prática: Python no computador, IDE e PowerShell. Não há execução Python no navegador.
Atelier: edite, copie, baixe ou reinicie os arquivos na página. A prévia CSS é isolada; a saída Python é registrada manualmente.
Preserve a pasta assets inteira junto de lessons e atividades. A exportação inclui rascunhos modificados do Atelier, não arquivos externos.
Recarregar limpa as respostas; exporte antes de fechar. O download não envia nada ao professor.
A01: 180 minutos, incluindo 15 de pausa. Abra atividades/A01/inicial.
Execute python primeiro_programa.py, python leitura.py e python diagnostico.py.
Sem pacotes Python externos na A01. PENDENTE no arquivo inicial é uma lacuna intencional.
Registre em atividades/A01/evidencias.md; entregue o registro exportado e seus arquivos Python.
A02: 180 minutos, incluindo 15 de pausa. Comece pela preparação na abertura da aula.
Crie uc9-a02/docs em uma área de atividades autorizada, com nome livre para não substituir trabalhos. Salve ou copie os seis materiais dos links ou de atividades/A02 do pacote extraído.
Abra uc9-a02 no VS Code, confira os nomes e salve/reabra o briefing. Preencha os quatro documentos na ordem das atividades; CSV e guia são consulta.
Entregue briefing.md, requisitos.md, backlog.md, evidencias.md e a exportação da página. Git é inspecionado com acompanhamento; uma raiz existente exige avaliação antes de inicializar.
Não há programa Python para executar nem pacote para instalar na A02. Auditoria CSS trata só da página didática. Dicas não são gabarito; cartões e opções são embaralhados.
A03: 180 minutos, incluindo 15 de pausa. Comece por tabela-rastreio.md e pseudocodigo.md em atividades/A03 antes de executar.

Sem bibliotecas externas. casos.csv é consulta; não é carregado pelo programa. Entregue tabela, pseudocódigo, evidências, retirada.py e exportação da página.

Revise os seis arquivos e o conteúdo staged antes do commit local, sem remoto. Entregue código, README, evidências e exportação; não envie .venv/.git/caches/segredos.
